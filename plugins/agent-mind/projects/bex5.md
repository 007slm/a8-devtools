# 项目详情卡片：BeX5-V38-turbo (测试靶场)

- **物理绝对路径**：`E:\BeX5-V38-turbo`
- **生态位定位**：`test-bed`（本地测试验证环境，非业务源码仓库）
- **核心定位**：全量业务运行时测试宿主环境。
- **环境组成**：
  - `apache-tomcat`：Java 应用服务器；
  - `mysql`：源数据库实例（端口与数据字典真源）；
  - `runtime` / `model`：BeX5 业务平台核心模型库与运行时；
  - 一键启动脚本：`启动BeX5运行平台.bat`、`启动MySQL数据库.bat`。
- **Agent 操作铁律 (Redlines)**：
  1. **绝对只读，严禁修改业务源码**：BeX5 只是用来跑集成对拍的靶场，绝不是你正在开发的业务代码库；
  2. **驱动集成验证**：仅允许将 `a8-turbo` 编译出的 `turbo-jdbc-driver.jar` 放入测试容器的 lib 路径或通过配置接入；
  3. **数据字典真源**：本地 MySQL 的物理元数据是 `a8-turbo` 缓存类型强校验的基准真相。
