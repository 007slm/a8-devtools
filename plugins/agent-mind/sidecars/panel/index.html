跨项目渐进式披露原则

日常单工程开发仅需知晓自身生态位，严禁过度读取其他仓库源码；跨项目联调前请严格核对下方的依赖契约与靶场只读红线。

a8-turbo CORE 生产核心

生产级智能数据库加速代理系统与 Web 前端加速网关。三进程独立交付：数据面核心 (:8010/:8330)、Web 网关 intake (:8443/:8090)、控制台 ui (:8011)。

● 门禁: mvn compile 100% · DuckDB 强类型 输出驱动至 BeX5 对拍
a8-devtools TOOLING 辅助底座

面向 Windows 的高性能开发者效率底座平台。包含 WinFsp 写时复制虚拟文件系统 (cowfs，C盘零占用)、任务栏实时网速悬浮条、系统设置中心及全局架构治理插件。

● 门禁: cargo check 0 错误 · 零黑窗 为 Turbo 提供差异隔离
BeX5-V38-turbo TEST-BED 验证靶场

本地全量业务运行时测试宿主环境（Tomcat、MySQL、Runtime）。用于部署 A8 驱动与网关，进行真实压测与本地缓存字段类型物理对拍。

⚠️ 绝对只读红线：禁止改动其业务源码 仅支持驱动无侵入挂载
a8-whisper TOOLING 辅助语音

本地语音识别与实时转录服务底座，为开发者语音指令提供离线低延迟转录支持。

● 运行状态: 独立就绪 开发者工作台组件
⚡ 代码库主人翁心智 (Code Ownership)

“这是你的代码库，架构设计和构建方式由你说了算，并且你将持续在上面开发构建。”

主动消除同类重复代码，就地根治显见坏味道；坚决杜绝“套娃打补丁”与“报丧不修复”的过客心态。

1. 演化契约与零擅自兼容

任何过渡层、废弃接口或双轨逻辑必须用户明确批准方可保留，未经批准彻底删除。重构时严禁“只建新房不拆旧房”，必须执行逆向清缴。

2. 系统边界与纯净隔离

无侵入客户端 SDK 严禁依赖 Spring Boot、Netty 等重型服务端容器；模块遵循严格单向依赖，底层库严禁反向污染宿主应用。

3. 并发安全与热路径性能

高并发数据面读取热路径严禁在方法签名声明 synchronized；严禁心跳/批处理流水线中增加跨线程、跨数据源的反查探测与隐式防抖。

4. 实现规范与错误物理第一现场

同一核心领域能力全工程唯一定义路径；严禁吞掉异常用默认空值继续，失败必须保留物理错误第一现场，保留人工可接管状态。
