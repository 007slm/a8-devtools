# 上下文与 Token 预算契约 (TOKENS.md)

> 本契约严控 `< 1KB`，固化日常研发 4 条核心节流规则：

1. **先搜后读**：查代码先用 `rg` 定位行号再分段读，不整读超大文件或锁/构建产物。
2. **局部送审**：增量开发运行 `a8-judge` 优先带 `--paths <路径>`，避免全仓 Diff 分块膨胀。
3. **输入降噪**：长编译/测试日志重定向至 `logs/` 或只看尾部摘要；高噪 HTML/邮件先经 `strip_html_text.py` 清洗。
4. **子代理分层**：轻量检索/探针优先用 `flash` 等低成本模型；常规小改在主会话完成，复杂跨模块任务再派子代理。

> 警戒线：看板「可观测」中单次 `a8-judge` 超 `30k tokens` 或 `diff_chunks >= 3` 时，核查遗漏过滤项或拆分改动。
