# 上下文与 Token 预算契约 (TOKENS.md)

> 本契约严控 `< 1KB`，固化日常研发 5 条核心节流规则：

1. **先搜后读**：查代码先用 `rg` 定位行号再分段读，不整读超大文件或锁/构建产物。
2. **局部送审**：增量开发运行 `a8-judge` 优先带 `--paths <路径>`，避免全仓 Diff 分块膨胀。
3. **输入降噪**：长编译/测试日志放 `logs/` 或只看尾部摘要；高噪 HTML/邮件先用 `strip_html_text.py` 清洗。
4. **子代理分层**：大日志、全量测试与剖析进隔离子代理（轻检索用低成本模型），主会话仅收结论与 `file:line` 并亲审 Diff；换向或重试默认新建干净子代理防污染。
5. **按可验证单元推进**：绿态 -> 单步改动 -> 立即校验 -> 下一步，不攒错。

> 警戒线：看板「可观测」中单次 `a8-judge` 超 `30k tokens` 或 `diff_chunks >= 3` 时，核查遗漏过滤项或拆分改动。
