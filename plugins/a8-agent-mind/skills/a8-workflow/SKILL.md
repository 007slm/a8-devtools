# A8 研发主线工作流 (`a8-workflow`)

本技能只保留**日常研发主线真正高频需要的核心流程纪律**，按任务性质路由至 5 份精简指南，并与全局规则（[mind-rules.md](../../rules/mind-rules.md)、[TOKENS.md](../../rules/TOKENS.md)）、验证地图（`<repo>/docs/verify.md`）及手动大招（`/a8-prompt`、`/a8-dsh-review`、`/a8-ui-verify`、`/a8-trace`、`/a8-commit`、`/a8-improve`）协同。

> **免开豁免**：1～2 行清晰改动、单一配置微调、纯文案润色或直接技术问答，改完跑通局部校验即可，不必强套流程。  
> **问路模式**：用户问“我想做 X，怎么推进最稳？”时，只给推荐步骤，不擅自改码。

---

## 一、 接单对齐门禁（动工前 3 条）

1. **复述最小边界**：长篇或模糊需求先用 2～3 句平实中文复述真实目标、完成判据与最小变更范围；有歧义先核对，不猜着开写。
2. **挑战复杂路线**：动工前核对语言/框架/本仓是否已有更简官方方案；若有，直说一次理由与替代方案待确认；想法尚粗糙时可引导先敲 [`/a8-prompt`](../a8-prompt/SKILL.md)。
3. **切话题重置路由**：同会话切换新问题类型时，立刻重新走下表选指南，防止旧任务惯性带偏当前动作；涉及界面/看板/交互卡片自动叠加 [a8-ui-design](../a8-ui-design/SKILL.md)。

## 二、 5 大研发主线路由表

| 任务场景 | 命中指南 | 一句话硬禁区 |
| :--- | :--- | :--- |
| **查原理、追历史动机、评估改动爆炸半径、活进程取证** | [guides/analyze.md](guides/analyze.md) | 严格只读，**严禁改动业务源码** |
| **缺陷复现与根治、核验已有修复、连修不动查前提** | [guides/bug-fix.md](guides/bug-fix.md) | 先用最轻量真实路径复现再修，不自动拉重型 UI/端到端 |
| **慢点排障、指标调优、耗时与吞吐对比实验** | [guides/perf.md](guides/perf.md) | 仅用户点名调优时启用；无基线禁优化，数字必过防伪 7 问 |
| **新功能、跨边界改形、状态机、纯结构重构** | [guides/feature.md](guides/feature.md) | 先定数据形状与状态不变量；不自动多方案实做对比 |
| **跨阶段大工程、无人值守循环与断点续跑** | [guides/long-task.md](guides/long-task.md) | 进度只认磁盘实测副作用，严禁放宽完成谓词 |

## 三、 4 条通用工程纪律（严控 Token 开销）

1. **真实证据标签**：只陈述亲眼读过的路径、符号名与实跑输出，关键结论标 `[实测]` / `[推断]` / `[待确认]`。
2. **按风险轻量验绿（拒绝盲目重测）**：动工先看 `AGENTS.md` 与 `<repo>/docs/verify.md` 了解边界；日常开发优先用最廉价的局部单测、编译与 `scripts/lints/` 验证（禁 Mock 假绿），仅改动触及真实外部契约/驱动/端口/构建产物或用户点名时才跑最小实机表面。
3. **3 大高耗 Token 动作严禁自动触发**：除非用户显式要求或主动调用对应命令，**严禁** AI 自行触发：① 浏览器 UI 自动化（`/a8-ui-verify`）；② 多方案交叉实现对比 / 独立对抗找茬子代理；③ 重型端到端反复跑测或多轮 A/B 压测循环。
4. **小步验绿与上下文节流**（对齐 [TOKENS.md](../../rules/TOKENS.md)）：绿态 → 单步改动 → 立即局部验绿 → 下一步；批量改造用可复跑脚本自证；大日志留隔离子代理，主会话只收结论与 `file:line`。可逆改动路线对齐即直接干完汇报，不可逆操作或产品偏好停步请示。

---

## 四、 A8 统一交卷收口（4 步）

1. **主会话自查注释与去水**：按 `guides/feature.md` 注释白名单直接自查 Diff 删废话/借口注释（无需额外起子代理）；汇报去 AI 套话与未入 `docs/glossary.md` 的黑话。
2. **门禁与轻量实证通过**：跑通目标仓编译、局部单测与 `scripts/lints/`（按需补跑 `docs/verify.md` 最小实机项；浏览器验收仅在用户主动敲 `/a8-ui-verify` 时执行）。
3. **双层文档日间轻更**：常规小改不建工作记录；触及架构/边界/契约/深层根因时写 `docs/records/YYYYMMDD-...md` 并在当前上下文顺手轻更 `docs/evergreen/`、`docs/verify.md` 与 `AGENTS.md`（**禁起 `docs-sync` 子代理**，全量对齐交每晚 20:00 定时任务）。
4. **40 行以内交卷简报**：按「目的 / 改动点 / 否决的替代方案 / 影响面与未测边界 / 实测验证结果」汇报（长日志落 `logs/` 贴路径）。需审完整过程取舍随时敲 [`/a8-trace`](../a8-trace/SKILL.md)；落库提交走 [`/a8-commit`](../a8-commit/SKILL.md) 强制红线闸门。
