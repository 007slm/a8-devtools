# SPEC：门户 Hero 概览与仓库双层治理文档浏览器

- **日期**：2026-11-20
- **状态**：已落地（当时有效）
- **域**：dashboard-and-workflows.md, agent-mind-governance.md
- **取代**：无

---

## 1. 问题与目标

- **要解决的问题**：工作台多处功能入口（`Hosts`、代码审核、心智治理、DSH 终审、每日提案、仓库地图）直接落入细节区缺少门户级 Hero 概览；各仓库双层治理文档（常青、工作记录、暂缓/废弃、总索引）在看板中没有统一分域查阅与回链跳转入口；且工作记录自身缺少标准化模板与事后失效/标废闭环，源码解析层此前堆砌了多种非标前缀兼容分支。
- **设计目标**：构建统一素净风格 `PortalHero` 概览区、双端同构 `docs/` 扫描与 `RepoDocsBrowser` 浏览器，并以“单一标准工作记录模板 + 无脏兼容解析 + `WORK_RECORD_SCHEMA` 门禁”彻底清洗工作记录生命周期。

## 2. 核心设计与结论

1. **统一门户 Hero 概览（`PortalHero.tsx`）**：
   - 采用 `a8-ui-polish` 素净细线容器（无重彩渐变/阴影），为 `App.tsx`（`hosts`）、`CodeReviewTab.tsx` 及 `AgentMindView.tsx`（`rules` / `reviews` / `proposals` / `projects`）补齐定位说明、状态徽标与核心指标栏。
2. **双端同构扫描与只读权限边界（`agent_mind.rs` & `main.mjs`）**：
   - `HostProjectCardDto` 与 `parseReposMd` 新增 `readme_rel_path`（探测仓库根目录 `README.md` / `readme.md`）；
   - `is_allowed_repo_governance_rel` / `isAllowedRepoGovernanceRel` 在 `writable == false` 时放行仓库根目录 `README.md` 与 `docs/**/*.md` 读取（`read_agent_mind_file` / `/api/agent-mind/read` 传独立参数 `repo_code` + `rel_path`），写入守卫维持不变；
   - **零脏兼容单一解析路径**：`parse_doc_meta` / `parseRepoDocMeta` 从前 20 行仅按唯一标准 `- **状态**：<value>` 提取状态，结合文件名 `YYYYMMDD-<TYPE>` 提取日期与类型；`classify_repo_doc_tier` / `classifyRepoDocTier` 按 `evergreen/`、`deferred/` 与 `records/`（状态为 `已废弃*` 或 `已暂缓*` 时归入 `deferred`）精确归类；同步彻底废弃历史过渡产物 `docs/INDEX.md`（`AGENTS.md` 已直接挂接常青文档，文档浏览器直接扫描物理 `docs/` 目录），代码移除对 `index.md` / `'index'` 的特殊分支。
3. **用户视角三段主导航与文档浏览器（`RepoDocsBrowser.tsx` & `AgentMindView.tsx`）**：
   - **仓库详情三段结构**：点进仓库地图卡片后，默认第一屏为 **「主页」**（渲染该仓根目录 `README.md`，并在主页副栏提供 **「仓库地图档案」** 按钮抽屉式查看/编辑 `repos/*.md` 说明与跨仓关联）；次屏聚焦 **「常青文档」**（`variant="evergreen"`，仅列 `evergreen/*.md`，支持文内渐进披露回链下钻与原位返回）；第三栏 **「docs 文档」**（`variant="docs"`）仅平铺非常青 `docs/` 文件（不重复列出常青文档），不做冗余分类 Tab，以搜索框配合清晰 Tag（`SPEC` / `ADR` / `BUG` / `暂缓` / `已废弃` / `部分失效`）表达类型与状态；
   - **可收起列表与全宽沉浸阅读**：`RepoDocsBrowser` 左侧文档列表支持点击顶栏 `PanelLeftClose` / `PanelLeftOpen` 按钮一键收起/展开，收起后右侧阅读区自动扩为 12 列全宽；
   - 心智治理 `规则规范 → 治理文档` 子页复用同一浏览组件（`variant="all"`）；对 `已废弃`/`部分失效` 记录渲染列表 Tag 及文章顶部警示条。
4. **插件级工作记录模板、双向标废与 Lint 门禁**：
   - 新增 [`templates/work-record.md`](../../plugins/a8-agent-mind/templates/work-record.md) 并接入 `mind-rules.md` 与 `docs-curator.md`，固化 **4 项精简元信息头（日期 / 状态 / 域 / 取代，剔除易漂移的关联源码栏）**、4 段骨架及“旧设计被推翻时就地贴 `[已失效]` / `[部分失效]` 横幅”；新增 `scripts/lints/check_work_records.mjs`（`WORK_RECORD_SCHEMA`）自动检验结构合规并禁止 `docs/` 下出现游离或已废弃文件（含 `INDEX.md`）。
