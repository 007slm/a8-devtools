# SPEC：远程共享进程监控与任务栏上沿红色流光带警示

- **日期**：2026-11-27
- **状态**：已落地（当时有效）
- **域**：desktop-tray-and-settings
- **取代**：无

---

## 1. 问题与目标

- **约束与现象**：Windows 没有公开的全局 API 可直接判断“当前屏幕正在被远程观看或共享”（抓屏可能走 DXGI、WGC、GDI 或镜像驱动，不像摄像头/麦克风有统一的隐私门禁）。用户在开启腾讯会议、向日葵、ToDesk 等软件时，容易忘记软件处于开启或后台驻留态而切出敏感信息；同时要求检测不能读取 GPU 性能计数器（避免影响游戏性能），也不能读取第三方软件磁盘日志（避免磁盘 IO 负担），且警示效果不能影响正常操作、不能被远程对方看到。
- **目标与非目标**：
  - **目标**：在 `modules/devtools` 内实现纯 Win32 原生进程名监控与任务栏上沿 24px 红色流光带提醒，并在工作台顶栏与设置页直接显示当前命中的进程名与 PID 便于排查。
  - **非目标**：不探测未知木马静默截屏；不读取 GPU VideoEncode 指标或第三方软件日志；不修改系统全局主题色、不注入 `explorer.exe`；不保留四周红框或多样式切换。

## 2. 核心设计与结论

- **最终决定 / 契约**：
  1. **纯内存进程名监测（`modules/devtools/src/screen_alert.rs`）**：每 `2000ms` 调用 Win32 `CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS)` 枚举进程名与 PID，按大小写不敏感匹配并自动补 `.exe` 归一化（默认监控 `wemeetapp.exe`、`SunloginClient.exe`、`ToDesk.exe`，可在 `AppSettings.screen_alert_processes` 自定义）；开关关闭时跳过快照扫描。
  2. **任务栏上沿 24px 红色流光带**：独立 Win32 消息线程管理无 Owner 顶层窗口（`WS_POPUP` + `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_TOPMOST | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`），鼠标完全穿透且不抢焦点；对主/副屏任务栏（`Shell_TrayWnd` / `Shell_SecondaryTrayWnd`）内侧边缘绘制 6px 亮红核心 + 18px 柔光渐变，复用 DIB 内存表面以 ~30 FPS 渲染双光波横向流转；非警示态立即 `KillTimer` 并 `SW_HIDE` 实现闲置零占用。
  3. **对远程观看者隐身**：所有警示窗口创建后调用 `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)`（Win10 2004+ 公开 API），确保本机肉眼可见而屏幕共享/远控画面不可见。
  4. **触发原因透明可查**：`ScreenAlertStatusDto` 返回 `matched_details`（进程名、PID 列表、实例数），并通过 `get_screen_alert_status`、`set_screen_alert_preview` 与 `screen-alert-status` 事件同步至前端，在主窗口顶栏实时亮出命中进程胶囊并在「系统设置 → 偏好设置」逐项展示 PID（辅助识别最小化到系统托盘的后台驻留进程）。
- **否决备选与代价**：
  - **否决修改系统任务栏主题色或调用未公开 `SetWindowCompositionAttribute`**：会连带污染全局主题色或在 Win11 22H2+ XAML 任务栏下被反复重置/遮挡。
  - **否决 GPU 编码器检测与远控日志监听**：用户明确排除以防影响游戏性能与引入持续磁盘 IO，代价是仅进程后台驻留（如腾讯会议关闭主窗后缩入托盘）也会触发提醒，因此通过 UI 直接展示命中进程名与 PID 化解疑惑。
  - **否决四周 4px 红色警戒框**：实机对比后收敛为单一 24px 任务栏上沿流光红带，移除样式枚举与切换配置避免复杂度残留。
- **重评触发条件**：若未来 Windows 开放系统级“桌面正在被捕获”官方隐私查询 API，或用户需要区分“仅托盘挂机”与“正在共享/被控”状态时，再评估按进程补充轻量窗口特征探测。

## 3. 当时验证范围

- **已验证**：
  - 前端构建：`modules/devtools/web` 执行 `npm run build`（`tsc -b && vite build`）通过，核验 `modules/devtools/ui/index.html` 维持经典 IIFE 产物；
  - Rust 测试：`cargo test --workspace` 全绿（`devtools` 23/23 通过，含 `screen_alert::tests` 进程名与 PID 归组、任务栏光带几何贴合、双光波峰值边界 3 项单测）；
  - 实机运行：`cargo build --release -p devtools` 零警告通过，脱离前台重启 `target/release/a8-devtools.exe`（PID `106508`）实测命中本机托盘驻留 `wemeetapp.exe`（PID `138644`），验证光带亮起与流光效果。
- **未覆盖 / 依赖边界**：未在多显示器混合 DPI 与任务栏停靠左/右/顶边缘环境做实机视觉复测；`WDA_EXCLUDEFROMCAPTURE` 在 Win10 2004 以下系统会静默降级为普通可见分层窗。
