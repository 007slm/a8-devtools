## 1. 战略定位与立项背景 (Motivation)

在开发者百宝箱平台（`a8-devtools`）中，为了赋能所有现代企业级项目（如 `a8-turbo` 及其他后端微服务系统）实现自动化、高质量的架构治理门禁，彻底解决传统静态分析（ArchUnit）依赖类名正则猜度导致的高误判、高漏判泥潭，正式确立打造通用 Antigravity 插件 **`arch-judge`**。

---

## 2. 核心架构与决策记录 (Key Decisions)

### 2.1 纯 Agent-Native 插件驱动形态（砍掉冗余 CLI）
- 坚决贯彻 YAGNI 原则，不搞多余的外部 npm/pip 打包发布工具链；
- 100% 走 Antigravity 原生 Plugin 体系，以专职只读 Subagent (`arch-judge`) 驱动，天然享有 UI 独立会话树透明追踪能力。

### 2.2 两阶段审查流水线 (Two-Phase Pipeline)
- **阶段一（调查官 - Thinking ON）**：在只读沙箱中，顺着 Git Diff 主动探索全工程调用方、追查生命周期与项目 ADR 批准事实；
- **阶段二（Jev 终审法官 - Thinking OFF / Strict Schema）**：在输出结论时关闭思考链，对照 4 大正交维度，直接按照标准 `ArchitectureVerdict` Schema 输出布尔判定与置信度，秒级响应，0 废话。

### 2.3 4 大正交维度与纯通用元特征路由 (Zero Project Hardcoding)
将架构红线按正交关注点聚合成 4 个互不重叠的类别，杜绝“一锅端导致大模型注意力稀释丢检查项”，同时杜绝“单条调用的 Token 浪费”：
1. `lifecycle_and_evolution`：生命周期闭环、零擅自向后兼容；
2. `topology_and_boundaries`：客户端 SDK 纯净隔离、模块单向分层；
3. `concurrency_and_performance`：数据面热路径无排他锁、杜绝幽灵轮询；
4. `implementation_hygiene`：核心能力单一解析路径、错误物理第一现场保留。

通过纯通用的语法元特征（`import`、公开方法签名、`synchronized`/锁原语、`catch`/异常）实现自适应毫秒级特征路由。

### 2.4 Generative UI 紧凑型现代报表
- 自动将 Jev 结构化决断编译为高质感 HTML 卡片，通过 `<agent-embed>` 内嵌到对话流中；
- 紧凑布局（高密度 2x2 网格、折叠审计抽屉、微发光与状态徽章），自适应 Antigravity 语义设计变量。
